# News Category Predictor

Classifies BBC news articles into topic categories with classical NLP.

## Contents
- `News_Category_Predictor.ipynb`: text preprocessing (NLTK), TF-IDF features, and SVM and ensemble classifiers, evaluated with classification reports and confusion matrices.
- `BBC News Train.csv`: training data.
- `05-Design and Analysis of News Category Predictor.pdf`: the accompanying paper.

## Stack
Python · scikit-learn · NLTK · Pandas · Matplotlib
